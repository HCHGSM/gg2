# مرجع واجهة برمجة التطبيقات (API Reference - POS & ERP System)

يوضح هذا المستند الوظائف والخدمات الأساسية (Services) المعمارية داخل نظام المبيعات ونقاط البيع المتكامل.

## 1. خدمة المصادقة (`AuthService`)
- `authenticate(username, password)`: التحقق من اسم المستخدم وتشفير كلمة المرور عبر `Bcrypt`، وتحديث وقت آخر تسجيل دخول وتسجيل الحدث في `AuditLog`.
- `change_password(user_id, old_password, new_password)`: تغيير كلمة المرور بأمان مع التحقق من صحة الكلمة القديمة.

## 2. خدمة المنتجات والمخزون (`ProductService`)
- `get_all_products()`: جلب قائمة جميع المنتجات التجارية.
- `add_product(data, user_id)`: إضافة منتج جديد مع التحقق من صحة البيانات وتسجيل حركة المخزون الأولية.
- `update_product(product_id, data, user_id)`: تعديل تفاصيل المنتج.
- `delete_product(product_id, user_id)`: حذف منتج من النظام بأمان.

## 3. خدمة المبيعات ونقاط البيع (`SalesService`)
- `create_sale(sale_data, items_data, user_id)`: إنشاء فاتورة مبيعات جديدة، خصم الكميات من المخزون، تسجيل حركات المخزون (`OUT`)، تحديث أرصدة العملاء، وتسجيل الدفعة النقدية أو البنكية في الحسابات المالية.
- `get_all_sales()`: جلب سجل الفواتير مرتبة تنازلياً.

## 4. خدمة المالية والحسابات (`FinanceService`)
- `add_expense(data, user_id)`: تسجيل المصروفات وخصمها التلقائي من الصندوق النقدي.
- `add_revenue(data, user_id)`: تسجيل الإيرادات الأخرى وإضافتها للصندوق.
- `get_accounts()`: عرض أرصدة الصناديق والحسابات البنكية.

## 5. خدمة التقارير (`ReportService`)
- `get_dashboard_stats()`: حساب إجمالي المبيعات، الأرباح الصافية، المشتريات، المصروفات، وعدد المنتجات ذات المخزون المنخفض.
- `export_sales_excel(file_path)`: تصدير سجل المبيعات الكامل إلى ملف Excel (`.xlsx`).
