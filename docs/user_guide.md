# دليل المستخدم الشامل - نظام المبيعات ونقاط البيع (POS & ERP User Guide)

مرحباً بك في دليل التشغيل السريع لنظام المبيعات ونقاط البيع المتكامل بمستوى تجاري احترافي.

## 1. تسجيل الدخول الأول
عند تشغيل البرنامج لأول مرة، استخدم بيانات المدير الافتراضية:
* **اسم المستخدم:** `admin`
* **كلمة المرور:** `admin123`

## 2. لوحة التحكم (Dashboard)
تعرض لك اللوحة نظرة شاملة وفورية على:
* إجمالي المبيعات والأرباح والمشتريات.
* تنبيهات المنتجات التي وصلت للحد الأدنى من المخزون.
* جدول أحدث الفواتير المسجلة.

## 3. نقطة البيع السريع (POS Terminal)
* قم بمسح الباركود أو البحث عن المنتج بالاسم أو الكود (SKU).
* اضغط على (➕ إضافة) لإضافة المنتج إلى سلة المشتريات.
* حدد طريقة الدفع (نقدي أو تحويل بنكي).
* اضغط على زر **إتمام البيع وإصدار الفاتورة** ليتم خصم المخزون وتسجيل الحركة المالية فوراً.

## 4. إدارة المخزون والمنتجات
* يمكنك إضافة منتجات جديدة، تحديد أسعار الشراء والبيع، وضبط الحد الأدنى للتنبيه عند نفاد المخزون.
* النظام يولد تلقائياً منتجات تجريبية جاهزة للاستخدام الفوري عند التشغيل.

## 5. التقارير والتصدير
* من شاشة التقارير، يمكنك تصدير تقارير المبيعات الشاملة إلى ملفات **Excel** بضغطة زر واحدة.
