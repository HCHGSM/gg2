# وثائق الهندسة المعمارية للنظام (POS & ERP System Architecture)

## نظرة عامة
تم بناء النظام بمعمارية برمجية متقدمة (Layered Architecture / MVC Pattern) تضمن الفصل التام بين طبقة قواعد البيانات (Data Layer)، وطبقة منطق الأعمال والخدمات (Service Layer)، وطبقة واجهة المستخدم الرسومية (Presentation Layer).

## تفاصيل الطبقات
1. **طبقة قاعدة البيانات (`pos_erp/database/`):**
   - استخدام SQLAlchemy ORM للتعامل مع قواعد البيانات بمرونة عالية.
   - دعم كامل للعلاقات (Relationships)، المفاتيح الأساسية والخارجية، والقيود (Constraints).
   - نموذج تدقيق الحركات (Audit Logs) لتسجيل كل نشاطات المستخدمين.

2. **طبقة الخدمات (`pos_erp/services/`):**
   - `AuthService`: إدارة المصادقة المشفرة بـ Bcrypt.
   - `ProductService`: إدارة المنتجات والتصنيفات والمخزون.
   - `SalesService`: إدارة نقاط البيع وفواتير المبيعات وحركات الصناديق.
   - `FinanceService`: إدارة المصروفات، الإيرادات، والحسابات المالية.
   - `ReportService`: توليد التقارير وتصديرها إلى Excel و PDF.
   - `ReceiptService`: تنسيق الإيصالات الحرارية للطباعة.
   - `BackupService`: النسخ الاحتياطي التلقائي واليدوي.

3. **طبقة واجهة المستخدم (`pos_erp/ui/`):**
   - مصممة باستخدام إطار العمل القوي **PySide6 (Qt6)**.
   - تصميم عصري (Modern UI/UX) مستوحى من أنظمة SaaS العالمية (Stripe, Odoo, Linear).
   - ثيمات متقدمة (Light & Dark Mode) مع ألوان وتدرجات زاهية (Vibrant Gradients).

## ضمان الجودة والاختبارات
يحتوي النظام على حزمة اختبارات شاملة (Unit Tests) تضمن سلامة العمليات الحسابية والمالية وإدارة المخزون بدقة تامة.
