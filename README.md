# نظام المبيعات ونقاط البيع المتكامل (Ultra-Advanced POS & ERP System - Desktop & Web)

برنامج مبيعات ونقاط بيع ومخازن تجاري احترافي بمستوى عالمي، مصمم للعمل كـ **برنامج سطح مكتب (Desktop App)** عبر PySide6 أو كـ **تطبيق ويب سحابي متكامل (Web App)** عبر FastAPI و Tailwind CSS.

---

## 🎨 الواجهات وتصميم (UI/UX)
- **تصميم عصري فائق الجمال:** مستوحى من أحدث منصات الـ SaaS العالمية (Stripe, Odoo, Linear, Zoho).
- **ألوان وتدرجات زاهية (Vibrant Gradients):** أزرار تفاعلية مضيئة، بطاقات إحصائية ملونة، وواجهات مريحة للعين.
- **دعم كامل للغة العربية (RTL).**

---

## 🚀 كيفية تشغيل تطبيق الويب (Web App)
لتشغيل النظام كتطبيق ويب سحابي محلي:
```bash
python3 run_web.py
```
ثم افتح المتصفح على الرابط: `http://127.0.0.1:8000`

## 🖥️ كيفية تشغيل برنامج سطح المكتب (Desktop App)
لتشغيل الواجهة الرسومية لسطح المكتب:
```bash
python3 main.py
```
